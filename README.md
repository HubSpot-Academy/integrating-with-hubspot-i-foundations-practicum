# Integrating With HubSpot I: Foundations Practicum

## Custom Object List View

https://app.hubspot.com/contacts/51349175/objects/2-63442938/views/all/list

## Practicum Summary

This project demonstrates:

* Custom object integration with HubSpot CRM
* Displaying custom object records on a homepage
* Creating new custom object records through a form
* Express.js routing
* Axios API requests
* Pug templates

Routes implemented:

* GET /
* GET /update-cobj
* POST /update-cobj
