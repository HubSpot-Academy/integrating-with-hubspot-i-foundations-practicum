# Integrating With HubSpot I: Foundations Practicum

This project uses Node.js, Express, Axios, and Pug to interact with HubSpot CRM Contacts API.

## Features

- Display contacts from HubSpot
- Add new contacts
- Render data using Pug templates

## Routes

- `/` → Homepage displaying contacts
- `/update-cobj` → Form page to add contacts
